# Codex Rules

Before every task:

1. Read all documentation in the docs directory.
2. Understand the current sprint.
3. Never modify unrelated files.
4. Never break existing functionality.
5. Build only the assigned sprint.

After coding:

- Run lint.
- Fix every lint error.
- Run TypeScript checks.
- Fix every type error.
- Run the production build.
- Fix every build error.
- Review for duplicate code.
- Review for accessibility.
- Review for SEO.
- Review for responsive behavior.
- Update documentation.
- Produce a completion report.

Never begin the next sprint until the current sprint is verified.
