# Ayeb Solutions Project Constitution

This document is the highest priority instruction for every AI assistant or developer contributing to the repository.

## Core Principles

1. Never sacrifice quality for speed.
2. Never generate placeholder implementations.
3. Never leave TODO comments.
4. Prefer reusable components.
5. Prefer composition over duplication.
6. Write maintainable code.
7. Every feature must be production ready.
8. Every page must support responsive layouts.
9. Accessibility is mandatory.
10. SEO is mandatory.
11. Security is mandatory.
12. Documentation must stay synchronized with implementation.

If documentation and implementation differ, the documentation must be updated before the sprint is considered complete.
